SIGNÉ — SITE COMPLET

Cette archive contient le code source du site, les polices, les outils PDF,
les composants et la configuration.

UTILISATION DU SITE
Importer un PDF, dessiner une signature ou saisir son nom, la placer sur
une page, puis télécharger le PDF signé. Les documents sont traités dans
le navigateur, sans être envoyés à un serveur.

MODIFIER LE SITE
Les fichiers principaux sont :
- src/App.tsx : fonctionnement de l'application
- src/signature-dialog.tsx : création des signatures
- src/styles/globals.css : présentation et adaptation au téléphone
- src/lib/pdf-signing.ts : ajout des signatures au PDF
- public/ : polices et fichiers nécessaires à la lecture des PDF

POUR UN DÉVELOPPEUR
Installer Node.js (version 20.19 ou plus récente), puis, dans ce dossier :

  npm install
  npm run dev

Pour reconstruire la version de production :

  npm run build

Le dossier node_modules n'est pas fourni : npm install réinstalle les
dépendances à partir de package.json.
L'historique Git, les caches et les identifiants secrets sont exclus.

HÉBERGEMENT
Le projet est un site 100 % statique construit avec Vite + React. La
commande `npm run build` produit un dossier dist/ prêt à être déposé sur
n'importe quel hébergeur (Cloudflare Pages, Netlify, Vercel, GitHub Pages,
serveur web classique...). Il n'a besoin d'aucune base de données, d'aucun
serveur applicatif, ni d'aucune plateforme d'hébergement particulière.

Vous pouvez conserver ce dossier et le fournir à un développeur ou à une IA
pour demander des modifications ultérieures.
